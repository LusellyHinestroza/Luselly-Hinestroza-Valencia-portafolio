Sobre el proyecto

Esta aplicación del clima fue desarrollada utilizando JavaScript moderno y consumo de APIs en tiempo real. El objetivo principal del proyecto es permitir al usuario consultar el estado del clima de cualquier ciudad del mundo de manera rápida, visual y dinámica.

El sistema obtiene información meteorológica actualizada, incluyendo temperatura, humedad, velocidad del viento y condiciones climáticas generales. Además, cuenta con una interfaz moderna con animaciones y diseño responsive adaptable a diferentes dispositivos.

Durante el desarrollo se trabajó en el manejo de peticiones asíncronas, validación de datos, manipulación del DOM y optimización visual para mejorar la experiencia del usuario.
